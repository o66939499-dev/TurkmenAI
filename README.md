# TurkmenAI
AI-powered multilingual language identification system with a focus on Turkmen language.

TurkmenAI — Low-Resource Language Intelligence System

TurkmenAI is an AI-powered multilingual language identification system designed to recognize five languages, with special attention to the Turkmen language.

Supported Languages

- Turkmen
- Turkish
- Azerbaijani
- English
- Russian

Technology Stack

- Python
- Pandas and NumPy
- Scikit-learn
- Character-level TF-IDF
- Logistic Regression
- Google Colab

Model Performance

The model was evaluated on a balanced test dataset containing 7,000 sentences.

- Overall accuracy: 98.89%
- Turkmen accuracy: 99.0%

These results apply to the project's held-out test dataset and may differ on independent real-world data.

Key Features

- Five-language identification
- Confidence score estimation
- Short-text uncertainty detection
- Special focus on low-resource Turkmen language

Project Goal

To contribute to AI research for low-resource languages and improve the digital representation of the Turkmen language.

Author

Developed as an AI and language technology project.
